# Distributed and service comparison cases

These tests execute Storage entry points against selected pinned source cases and independently
computed expectations. The upstream programs are not linked or executed. Distributed remains a
source-only reference assembly; the service adapters exercise Infrastructure, one of the three
packable projects. No packaging behavior changes.

| Pinned source | Cases used | Local adaptation and differences |
|---|---|---|

| [transparency-dev Merkle RFC6962 tests](https://github.com/transparency-dev/merkle/blob/c39fbf350a405f68571bf4c42a6a518eb0a46a4b/rfc6962/rfc6962_test.go) (`c39fbf350a405f68571bf4c42a6a518eb0a46a4b`) | Empty and `L123456` leaf vectors, `N123`/`N456` internal-node vector, domain-separation collision and order cases | Internal hashing is exercised through public proof verification. | [PostgreSQL isolation corpus](https://github.com/postgres/postgres/tree/d7ec59a63d745ba74fba0e280bbf85dc6d1caa3e/src/test/isolation), [prepared transaction recovery](https://github.com/postgres/postgres/blob/d7ec59a63d745ba74fba0e280bbf85dc6d1caa3e/src/test/recovery/t/009_twophase.pl) (`REL_17_0`, `d7ec59a63d745ba74fba0e280bbf85dc6d1caa3e`) | `simple-write-skew.spec`: apple/pear write skew; `deadlock-simple.spec`: two shared-to-exclusive upgrades; `009_twophase.pl`: commit and abort prepared transactions after reopen | SQL predicates are expanded into enumerated point reads; this does not establish predicate/phantom tracking or SSI. | [Porcupine register model](https://github.com/anishathalye/porcupine/blob/b1a26c6975ee6009aab9a813a15872a86cd048f7/porcupine_test.go) (`v1.0.3`, `b1a26c6975ee6009aab9a813a15872a86cd048f7`) | Both `TestRegisterModel` operation histories: legal overlapping reads and an impossible new-then-stale observation | Original unique invocation/response ordinals retained, integer register model translated into the public bounded checker. Storage reports Inconclusive for pending/budget-bounded histories in separate executable contract tests. |
| [SQLite independent state fixture](../sqlite-kv-histories.json), generated by `scripts/generate-storage-oracle.py` | Three seeds × 96 committed mutations, every resulting map computed by SQLite | Replayed against object stores, event logs, checkpoints, compacted CDC + replay guards, and MVCC. Both memory and file service variants execute, with clean reopen every 16 mutations and lost replies after topic save every 17 mutations. SQLite isolation semantics are not projected onto the in-memory comparison stores. The fixture contains no copied SQLite implementation. |

The additional observed-remove history oracle uses event IDs, observed-remove event references,
and delivered-event sets, independent of Storage's private tags/counters. The causal replication
oracle uses a transitive operation DAG to compute maximal visible siblings, independent of the
implementation's vector-clock resolver. These verify finite histories, not universal convergence
or real-network liveness. Existing independent invariants cover the rest of the source-only
surface: lease/fencing/compare-exchange, linearizability-search counterexamples and inconclusive
results, durable decision/lock/message replay, versioned shard-map CAS, metadata-only rebalance,
hot-key routing, CRDT algebra and durable sync identity/tombstones. Those Storage-specific
contracts are not advertised as complete ports of any upstream product.

Physical power loss, kernel/filesystem durability across all platforms, remote object-store
providers, remote consensus transports, authenticated networking, multi-process deployment and
performance comparisons require external environments. This corpus does not certify them.
